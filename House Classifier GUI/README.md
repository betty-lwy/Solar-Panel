# House Image Classifier GUI

A Python GUI application for classifying house images.

## Requirements

### Python Packages

Install required packages using:

```bash
pip install pandas pillow openpyxl
```

## Configuration

```python
# Modify these paths before running
EXCEL_PATH = "path/to/your/house_data.xlsx"    # Path to your input Excel file
IMAGE_BASE_FOLDER = "path/to/your/images/"     # Path to root image folder
OUTPUT_EXCEL = EXCEL_PATH                      # Keep this to overwrite original file
```
